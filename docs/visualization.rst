Visualization
=============

The repository does not include a web UI. For a quick visual check of the
included example plants, run:

.. code-block:: bash

   python examples/plot_monthly_generation.py

This writes ``figures/example_monthly_generation.png`` with monthly generation
profiles for plants 171, 172, and 186. The ``figures/`` directory is ignored by
Git because generated plots should not be committed by default.
